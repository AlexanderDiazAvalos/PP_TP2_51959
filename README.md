# TP2 - Ejercicio 3

## Paradigmas de Programación - UTN FRM

### Descripción

Este proyecto corresponde al **Trabajo Práctico 2 - Ejercicio 3** de la materia Paradigmas de Programación.

### Funcionalidades

* Creación de estudiantes.
* Creación de eventos con una sala asignada.
* Creación de actividades dentro de los eventos.
* Inscripción de estudiantes en diferentes actividades.
* Serializar el eventoUniversitario.
* Deserializar el eventoUniversitario.
* Filtrado de actividades por tipo concreto:

  * `Charla`
  * `Taller`
  * `Curso`
    
* Obtención de la cantidad de actividades de cada tipo.
* Cálculo del costo de materiales correspondiente a cada tipo de actividad.
* Uso de listas (`List`) como resultado del filtrado.
